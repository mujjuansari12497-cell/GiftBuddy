PHONE-ONLY APK BUILD

1. Create a free GitHub account if you don't have one.
2. In Chrome on your Android phone, open github.com and create a new repository named GiftBuddy.
3. Upload all files from this ZIP, keeping the folder structure.
4. Open the repository's Actions tab.
5. Tap "Build GiftBuddy APK" if needed, then Run workflow.
6. Wait for the green check.
7. Open the completed workflow run -> Artifacts -> GiftBuddy-APK.
8. Download the ZIP artifact, extract it, and install app-debug.apk.

No PC is required. GitHub does the Android build online.
